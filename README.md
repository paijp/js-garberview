# gerberview

ブラウザだけで動く、プリント基板のガーバーデータ一式 (ZIP) のプレビューア。
サーバは使わず、ファイルはどこにも送信されない。`index.html` 1 枚で完結して
いるので、GitHub Pages で開いても、ダウンロードしてローカルで開いてもよい。

**https://paijp.github.io/js-gerberview/**

## 使い方

1. `index.html` を開く (GitHub Pages、またはダウンロードしてダブルクリック)。
2. ガーバー一式の ZIP (または個別ファイル) をドロップするか、「ZIP / ファイルを開く」で選ぶ。
3. 表示を切り替える。
   - **部品面 / 半田面** — レジスト・銅箔・シルク・穴を合成した基板の見た目。
     半田面は裏から見た向き (左右反転)。
   - **レイヤー** — 各レイヤーを色分けして重ねる。色は左の一覧で変えられる。
   - **黒背景 / 白背景** — 白背景は textpcb と同じ印刷向けの配色。部品面・半田面は
     レジストの下を黄、銅箔をシアン、シルクをマゼンタで重ね (乗算)、穴と外形は黒。
     レイヤー表示は表銅箔マゼンタ・裏銅箔シアン・シルク黄。
4. 操作: ホイールで拡大縮小、ドラッグで移動、Shift+ドラッグで距離を計測。

レイヤーの種類はファイル名 (Protel 拡張子 `.GTL` など、KiCad の `-F_Cu.gbr` など)
と、X2 属性 `%TF.FileFunction` から自動で判定する。外れたときは一覧の
セレクタで直せる。穴はスルー (PTH) とノンスルー (NPTH) を、X2 属性・KiCad の
ドリルファイル内コメント・ファイル名 (`NPTH`) から見分ける。ZIP 内の
`__MACOSX/` や `._*` は読み飛ばす。

`examples/textpcb-sample.zip` は [textpcb](https://github.com/paijp/textpcb) の
ガーバー出力で作ったサンプル。

## 対応範囲

- Gerber RS-274X: 円・矩形・長円・多角形アパーチャ (穴付き含む)、アパーチャマクロ
  (変数・式、図形 1/4/5/6/7/20/21/22)、直線・円弧補間 (G74/G75)、リージョン、
  極性 (LPD/LPC)、ステップ&リピート、アパーチャブロック、inch/mm。
- Excellon ドリル: METRIC/INCH、LZ/TZ、桁数指定、小数点付き座標、G85 スロット、
  ルーティング (G00/G01 + M15/M16)。
- ドリルを Gerber で出す形式 (textpcb の `hole.grb` など) も穴として扱う。

未対応: アパーチャ変換 (LR/LM/LS)、マクロ内の露光 OFF は層全体の
クリアとして近似、旧形式 RS-274D (アパーチャ定義が別ファイル)。

## 構成

- `index.html` — アプリ本体。`// @@lib-begin` 〜 `// @@lib-end` の間が
  ZIP 展開・Gerber/Excellon パーサ・レイヤー判定・SVG パス生成・外形線の
  ループ化で、DOM に依存しない。その後ろが SVG 描画と UI。
- `tests/run.js` — パーサの回帰テスト (`node tests/run.js`)。隣に textpcb の
  チェックアウトがあれば、その出力を読み戻すテストも走る。

描画は SVG で、拡大しても輪郭がぼやけない。拡大縮小・移動は viewBox を
動かすだけで、描き直すのは表示内容が変わったときだけ。各レイヤーを SVG の
mask にして色を付けて合成する (textpcb のプレビューと同じ考え方)。基板の形は
外形線の線分をつないだ閉ループを even-odd で塗って求め、閉じない場合は外接矩形。

## GitHub Pages

`main` に push すると `.github/workflows/pages.yml` がテストを走らせてから公開する。
初回だけ、リポジトリの Settings → Pages → Source を「GitHub Actions」にしておく。
